EletricSoftware.

Um sistema para Gerenciar Clientes Gerenciar Serviços Gerenciar Técnicos Gerenciar Ordem de Serviço Gerenciar Pagamentos Gerenciar Relatórios

O EletricSoftware é uma aplicação web desenvolvida durante o estágio supervisionado do curso de Engenharia de Software para a JRL Eletricista, empresa gerenciada por um eletricista autônomo responsável por instalações e manutenções elétricas residenciais e prediais. O sistema centraliza o cadastro de clientes, serviços, técnicos e ordens de serviço, além de controlar pagamentos, cobranças e relatórios financeiros.

Sobre o Projeto

Antes do EletricSoftware, todo o controle de clientes, serviços e pagamentos da JRL-Eletricista era feito de forma inteiramente informal por conversas no WhatsApp e anotações avulsas, sem qualquer persistência estruturada de dados. Essa forma de organização causava perda de informações, dificultava o acompanhamento financeiro e resultava em uma alta taxa de inadimplência, identificada pelo próprio cliente como o principal problema a ser resolvido.

O sistema segue uma arquitetura cliente-servidor: o front-end, em React, consome uma API REST desenvolvida em Spring Boot, responsável pelas regras de negócio, autenticação e persistência dos dados em um banco relacional PostgreSQL.

Java 25 Spring Boot 4.0.5 React 19.2 PostgreSQL 18.3 Spring Security + JWT Bucket4j Thymeleaf + OpenHTMLtoPDF Git & GitHub RUP

Casos de Uso

01 Gerenciar Clientes

Cadastro, consulta, edição e inativação das informações dos clientes, substituindo o controle informal por uma estrutura única e centralizada.

02 Gerenciar Serviços

Cadastro, visualização e edição dos serviços oferecidos pela empresa, usados posteriormente na criação das ordens de serviço.

03 Gerenciar Técnicos

Cadastro, visualização, edição e inativação dos técnicos responsáveis pela execução dos serviços prestados.

04 Gerenciar Ordem de Serviço

Criação e acompanhamento das ordens de serviço, relacionando clientes, serviços e técnicos envolvidos em cada atendimento.

05 Gerenciar Pagamentos

Registro e acompanhamento dos pagamentos realizados pelos clientes, com integração ao Asaas (sandbox) para cobrança.

06 Gerenciar Relatórios

Geração e visualização de relatórios com informações consolidadas sobre clientes, serviços e pagamentos, em PDF.

Tecnologias Utilizadas

Java 25

Linguagem principal do back-end, orientada a objetos e fortemente tipada.

Spring Boot 4.0.5

Framework REST do back-end, com Spring Security e autenticação via JWT.

React 19.2

Biblioteca do front-end, responsável pela interface web responsiva.

PostgreSQL 18.3

Banco de dados relacional utilizado para o armazenamento estruturado.

RUP

Rational Unified Process como processo de desenvolvimento do projeto.

Thymeleaf + OpenHTMLtoPDF

Geração dos relatórios do sistema em PDF a partir de templates HTML.
